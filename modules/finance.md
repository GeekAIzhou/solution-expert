# 投融资与财务模型

模型结构：
输入假设 → CAPEX → 融资 → 收入 → OPEX → 折旧 → 税费 → 债务 → 年度现金流 → 指标。

核心指标：
- 项目税后IRR
- 资本金IRR
- NPV
- 投资回收期
- DSCR
- EBITDA
- 利息保障
- 敏感性分析

## 回收期算法
1. 找到累计净现金流由负转正的年份。
2. 用该年度期初未回收金额除以该年度净现金流。
3. 回收期 = 上一完整年度 + 跨零所需比例。
4. 全生命周期仍为负时，明确输出“项目期内未回收”，禁止空白。

## 财务审计
逐项核对公式、引用、单位、税务、融资、折旧、现金流和指标口径。
