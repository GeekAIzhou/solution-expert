## 6. 统一8760模型
每小时至少计算：Load、PV、Charge、Discharge、SOC、GridImport、GridExport、Curtailment、ChargingLoad、Demand/Peak、ElectricityPrice。

基本电量平衡：
GridImport + PV + Discharge = Load + Charging + Charge + GridExport + Curtailment

储能约束：
0 <= SOC <= E_capacity
Discharge <= P_discharge
Charge <= P_charge
并检查SOC初始/末值、充放电效率及是否允许同小时同时充放电。

## 7. 收益模型
P01：节能收益 + PV收益 + 储能套利/需量收益。
P02：节能收益 + 储能收益 + VPP/需求响应/交易收益。
P03：充电服务费毛利 + 储能收益 + 需量优化收益。
P04：节电收益 + 合同服务费/运营收益（如合同存在）。

严禁把融资资金计入营业收入；严禁重复计算同一度电的节能、交易、绿电/绿证、碳收益。

## 8. EPC成本闭环
每个WBS必须形成：
编码｜设备/工程名称｜规格｜单位｜数量｜含税单价｜含税合价｜安装费｜设计费｜管理费｜税费｜来源｜边界说明

7380万元作为总控值；后续工程量×单价形成Bottom-up EPC，与7380万元Top-down预算进行差异审计。
