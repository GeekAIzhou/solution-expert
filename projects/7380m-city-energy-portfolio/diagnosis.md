# 7380万元城市综合能源项目群｜项目诊断 V0.1

## 1. 项目诊断结论
本项目应按“单项目经济性 + 城市级平台协同”双层模型建设。四个子项目分别形成节能、光伏、储能、充电、路灯及虚拟电厂资源池，最终通过VPP、能源管理平台、统一运维和电力交易形成组合运营模型。

当前可以锁定工程规模和投资额，但尚不足以锁定收益、IRR、回收期及DSCR。原因是四个子项目的8760负荷、当地电价、储能功率、充电利用率、节能率、融资条件等核心变量尚未完整输入。

## 2. 技术规模校验
- 总投资：7380万元，四项相加正确。
- 已知储能：16MWh。
- 已知储能功率：至少6MW；P03未给储能功率。
- P03充电桩额定功率：若120kW为单桩，则180台=21.6MW；该值为设备额定功率，不代表实际同时负荷。
- P01光伏：2MWp。
- P04路灯：1.2万盏 + 500智能杆试点。

## 3. 系统架构建议
资源层：2MWp光伏、16MWh储能、21.6MW级充电设备（待口径确认）、1.2万盏路灯、500智能杆、污水厂/运维中心可调负荷。

平台层：EMS + VPP聚合平台 + 充电运营平台 + 路灯智慧管理平台 + 能源数据中台。

市场层：峰谷套利、需求响应、虚拟电厂、绿电/绿证、电力交易等，具体参与方式必须按项目所在地市场规则核验。

财务层：CAPEX → 8760 → 收益 → OPEX → 融资 → 年度现金流 → 项目IRR/股权IRR/NPV/回收期/DSCR → 独立审计。

## 4. EPC造价审计重点
7380万元目前只能作为项目总投资输入，不能直接作为设备采购预算。后续必须拆成：设备费、材料费、安装费、设计费、项目管理费、调试费、平台软件、通信、并网/增容、施工措施、税费、预备费，并明确甲供/乙供及合同边界。

重点审计：
- P01储能系统与光伏是否含并网、消防、防水、浮体/支架等特殊边界。
- P02 5MW/10MWh储能是否包含PCS、升压、消防、EMS、并网及场站改造。
- P03 180台充电桩是否含配电、变压器、开关柜、箱变、充电运营平台、土建、线缆及停车场改造。
- P04 1.2万盏路灯是否为整体替换、节能改造或合同能源管理；500智能杆的设备边界需单独WBS。

## 5. 财务建模重点
### P01
核心收益：节能改造节电收益 + 光伏自用/上网收益 + 储能套利/需量收益。

### P02
核心收益：节能收益 + 储能套利/需量收益 + VPP/需求响应/电力交易收益；VPP收益必须以可调资源和结算规则为基础。

### P03
核心收益：充电服务费毛利 + 储能套利/需量收益；必须建立日/小时充电量曲线，不能用桩数直接乘满功率推导年收入。

### P04
核心收益：节电收益/服务费 + 智能杆运营收益（如有）+ 平台/运维收益（如合同约定）。
