# 7380万元城市综合能源项目群｜总体技术方案 V0.1

## 一、项目定位
建设“节能改造 + 光伏 + 储能 + 储充 + 路灯能源化 + 虚拟电厂 + 能源数字平台”的城市综合能源项目群。采用“四个子项目建设、一个能源平台统筹、一个VPP统一聚合、一个运营体系闭环”的总体架构。

本版为方案设计版，不作为施工图及最终投资报价。未确认参数统一标记【待确认】。

## 二、总体架构

### 1. 资源层
- P01污水厂：2MWp光伏 + 1MW/2MWh储能 + 节能负荷
- P02运维中心：5MW/10MWh储能 + 节能负荷
- P03停车场：180台双枪120kW充电桩 + 4MWh储能
- P04路灯：12000盏路灯 + 500个智能杆
- 可聚合资源：储能、充电负荷、污水厂可调负荷、运维中心可调负荷、路灯可调负荷

### 2. 平台层
建设统一能源数字底座：
- EMS能源管理
- VPP虚拟电厂聚合
- 充电运营平台
- 路灯智慧管理平台
- 能源数据中台
- 计量与结算
- 运维工单
- 财务/经营分析

### 3. 市场层
根据项目所在地及市场准入规则，逐步接入：
- 峰谷套利
- 需求响应
- 虚拟电厂
- 电力交易
- 绿电/绿证
- 其他符合规则的辅助服务

不得在未核验市场规则前锁定交易收益。

## 三、P01 融元污水处理厂方案｜1080万元

### 1. 建设内容
- 节能改造：重点针对曝气、泵类、风机、变频、电机及控制系统
- 2MWp光伏：优先采用池面/水池区域适配方案，结构、防腐、抗风及运维通道专项设计
- 1MW/2MWh储能：电池系统 + PCS + BMS + EMS + 消防 + 温控 + 升压并网
- 建设厂级能源管理系统，与污水厂生产控制系统保持边界隔离并实现数据交互

### 2. 运行策略
白天优先消纳光伏；根据负荷及电价安排储能充放电；在满足生产安全前提下进行需量优化。余电上网规则【待确认】。

### 3. 关键设计校核
- 水池结构荷载
- 浮体/支架防腐
- 防洪及极端天气
- 污水厂潮湿、腐蚀环境
- 光伏与储能消防
- 并网点容量
- 生产负荷不能因能源优化受到影响

## 四、P02 智慧城市运维中心方案｜2300万元

### 1. 建设内容
- 节能改造：空调、照明、动力、机房/设备等【按现场审计确认】
- 5MW/10MWh储能系统
- EMS能源管理
- VPP聚合控制
- 通信及边缘控制设备
- 电能质量及保护系统

### 2. 储能策略
建立“安全优先 + 峰谷套利 + 需量控制 + VPP响应”的多目标策略。正常时段优化SOC；收到市场/调度信号时预留可调用容量。

### 3. VPP资源
第一阶段以5MW/10MWh储能为核心；第二阶段接入运维中心可调负荷；后续可与污水厂、停车场、路灯资源统一聚合。

## 五、P03 公共停车场储充方案｜1800万元

### 1. 建设规模
- 180台双枪充电桩
- 120kW：暂按单桩额定功率，最终确认
- 理论额定设备功率21.6MW
- 4MWh储能，储能功率【待确认】
- 配套变配电、计量、监控、通信、充电运营平台

### 2. 核心策略
采用“有序充电 + 储能削峰 + 动态功率分配”。

充电桩不以额定功率长期运行，通过平台根据车辆SOC、离场时间、实时电价、站内功率上限和储能SOC进行动态分配。

### 3. 配电原则
以最大实际同时充电功率而非21.6MW理论额定值作为变压器容量优化依据，但必须结合充电负荷实测/预测曲线确定。

### 4. 运营模式
收入拆分为：
- 充电电费代收/结算
- 充电服务费
- 储能电费优化
- 其他平台/增值服务【如有合同依据】

## 六、P04 路灯能源化管理方案｜2200万元

### 1. 建设规模
- 12000盏路灯
- 500个智能杆试点
- 单灯控制及集中控制
- 智慧照明平台
- 通信网络
- 运行监测及故障工单

### 2. 节能策略
根据道路等级、时段、交通流量和天气条件实施分时调光，形成“按需照明”。

### 3. 智能杆
500个试点采用模块化设计，设备按实际需求配置，避免一次性堆叠无明确收益的设备。

### 4. 运营
建立远程监控、故障告警、工单、巡检、备件和能耗分析体系。

## 七、城市级VPP方案

### 1. 聚合资源
第一层：P02 5MW/10MWh储能
第二层：P01 1MW/2MWh储能
第三层：P03 4MWh储能【功率待确认】
第四层：充电可调负荷
第五层：污水厂/运维中心/路灯可调负荷

已知储能容量合计16MWh；已知储能功率至少6MW。

### 2. 控制闭环
预测 → 优化 → 指令 → 边缘控制 → 执行 → 计量 → 结算 → 复盘。

### 3. VPP收益
仅在对应市场规则、资源准入、基线、响应性能及结算机制满足条件后计入财务模型。

2. 实时监控
3. 能耗分析
4. 负荷预测
5. 光伏预测
6. 储能优化
7. 充电运营
8. 路灯管理
9. VPP调度
10. 电力交易与结算
11. 运维管理
12. 经营分析

## 九、建设实施阶段
### Phase 1
现场踏勘、能源审计、负荷测量、并网条件核查。

### Phase 2
初步设计、设备选型、8760建模、VPP资源评估、EPC预算。

### Phase 3
施工图、采购、施工、调试、平台上线。

### Phase 4
试运行、性能验收、收益基线确认。

### Phase 5
正式运营、VPP聚合、电力交易及持续优化。

## 十、方案控制指标
- 安全：消防、保护、通信、并网、生产安全优先
- 经济：以8760模型计算真实收益

- 财务：项目现金流与股权现金流分开
- 数据：所有关键假设有来源/状态
- 审计：公式级复核
- 运营：建设与运营一体化设计
