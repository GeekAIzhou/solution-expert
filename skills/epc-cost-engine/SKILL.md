# EPC工程量与造价引擎 Skill

## 造价链路
设计边界 → WBS分解 → 设备清单 → 工程量 → 询价/参考价 → 安装调试 → 措施费 → 管理费 → 设计费 → 税费 → 预备费 → EPC总价。

## WBS维度
按项目、子系统、专业、设备、材料、安装、调试和服务分层。

## 每项成本字段
编码、名称、规格、单位、数量、单价、合价、税率、含税价、不含税价、供应商/来源、备注。

## 必须明确
- 甲供、乙供和暂估价
- 含税/不含税
- 设备与安装边界
- 并网、消防、土建、通信和平台边界
- 预备费及价格波动
- 质保、备件和运维责任

## 校验
设备数量与容量匹配；工程量与技术方案匹配；分项合计与总价一致；税额可反算；单位和币种统一。
