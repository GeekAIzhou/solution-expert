# VPP虚拟电厂深度建模 Skill

## 目标
把分散的光伏、储能、充电、可调负荷、冷站、水泵、数据中心等资源建模为可计量、可预测、可调度、可结算的聚合资源。

## 资源模型
每个资源至少包含：额定功率、可调功率、最小/最大出力、响应时间、持续时间、恢复时间、可用时段、基线、计量点、通信方式、控制权限、可用率。

## 8760调度
建立小时级负荷、光伏、储能SOC、电价和市场事件序列。每小时必须满足功率平衡、SOC边界和设备运行边界。

## 优化目标
按项目规则选择购电成本最小、峰值最小、VPP收益最大、弃光最小、充电成本最小或综合目标。目标函数、约束和权重必须显式记录。

## 收益拆分
交易价差、需求响应、辅助服务、容量/需求管理、聚合服务费分别核算。禁止把同一调度动作产生的同一收益重复计入。

## 结算
申报 → 执行 → 实际计量 → 基线核算 → 偏差/考核 → 收益结算。模型必须保留基线、实际值和结算值三套数据。

## 风险
市场准入、规则变化、价格波动、基线争议、通信失败、响应不足、偏差考核和资源退出。

## 输出
资源池清单、可调能力曲线、8760调度结果、VPP收益表、考核表、敏感性分析和运营KPI。
