# Financial Modeling Skill

## 目标
建立可审计、可复核、可融资决策的综合能源项目财务模型。

## 标准模型层
输入假设 → 技术规模 → CAPEX → 融资 → 产能/负荷 → 收入 → OPEX → 折旧 → 税费 → 债务 → 年度现金流 → 项目指标 → 资本金指标 → 敏感性。

## 收入建模
按业务拆分并独立核算：
- 光伏节省/售电收入
- 储能峰谷套利
- 需量电费节省
- 充电服务费
- VPP/需求响应
- 电力交易
- 绿电/绿证/碳资产
- 节能收益
禁止同一收益重复计入。

## 核心指标
项目税后IRR、资本金IRR、NPV、投资回收期、DSCR、EBITDA、利润、现金流。

## 回收期
累计现金流首次由负转正：
Payback = 上一完整年度 + 期初累计未回收金额 / 当年净现金流。
若项目期末仍为负，显示“项目期内未回收”，不得返回空白。

## 公式审计
每次输出模型必须检查：
1. 单位
2. 年份
3. CAPEX
4. 收入
5. OPEX
6. 折旧
7. 税费
8. 借款与利息
9. 现金流
10. IRR/NPV
11. 回收期
12. DSCR
13. 交叉引用
14. 边界条件
15. 极端情景

## 交叉验证
至少进行三类验证：
- 会计恒等式验证
- 现金流累计验证
- 指标反算验证

## 输出
必须提供“关键假设表、年度现金流表、核心指标表、敏感性表、公式/口径说明”。
