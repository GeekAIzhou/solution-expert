# 综合能源项目 Skill

## 光伏
装机 → 发电量 → 自用 → 余电 → 电价 → 收益 → 衰减。

## 储能
容量/功率 → SOC → 充放电策略 → 效率 → 循环 → 峰谷套利/需量/VPP。

## 光储充
建立逐时能源平衡，优先消纳光伏，结合储能优化充电负荷。

## VPP
资源聚合 → 可调能力 → 预测 → 调度 → 市场交易 → 结算 → 运营。

## 电力交易
区分中长期、现货、绿电、绿证及代理购售电口径，按项目所在地市场规则测算。

## 零碳园区
源网荷储 + 节能 + 充电 + 碳管理 + 数字平台 + 运营。

## 节能改造
建立改造前基线、改造后能耗、节能量、投资和节能收益。

## 数据中心
IT负荷 → PUE → 配电 → UPS → 制冷 → CAPEX/OPEX → 单位算力能源成本。
