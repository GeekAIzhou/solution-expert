# 专业交付物生成 Skill

## 交付类型
Markdown、Word、Excel、PPT、银行可研、技术方案、EPC报价书、运营方案、投融资报告和政府汇报材料。

## 生成流程
内容架构 → 数据与假设表 → 正文 → 图表/架构图 → 目录与编号 → 格式排版 → 质量检查 → 交付说明。

## 统一要求
- 结论前置
- 章节层级稳定
- 表格注明单位和口径
- 图表有标题、编号和数据来源
- 待确认事项集中列示
- 正式材料不使用夸张营销话术
- 重要结论必须与模型结果一致

## 交付前检查
内容完整性、数字一致性、公式口径、页眉页脚、目录、表格分页、图表清晰度、文件可打开性和版本号。
