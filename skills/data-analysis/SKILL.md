# Data Analysis Skill

## 方法
数据采集 → 清洗 → 单位统一 → 异常识别 → 统计分析 → 建模 → 校验 → 可视化 → 结论。

## 能源项目重点
- 年/月/日/小时负荷
- 峰谷平电量
- 最大需量
- 光伏资源与发电量
- 储能SOC及充放电
- 充电桩利用率
- 电价时序
- 节能前后对比
- PUE
- 碳排放

## 8760分析
优先采用小时级模型；无8760数据时，明确采用典型日/典型月/行业假设，并标记数据质量等级。

## 数据质量
每个关键数据标记：
A=原始实测；B=权威来源；C=项目提供；D=行业假设。
不得把D类假设包装成实测数据。

## 可视化
优先：
负荷曲线、能源平衡、月度趋势、峰谷分布、投资构成、收益构成、现金流、敏感性。
正式材料避免无意义装饰。
