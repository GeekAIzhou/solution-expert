# 综合能源项目群投资组合 Skill

## 适用范围
污水厂、智慧运维中心、停车场储充、路灯、园区、数据中心及其他分布式能源项目组成的城市级项目群。

## 投资组合结构
项目清单 → 技术规模 → CAPEX → 年度收益 → OPEX → 融资 → 现金流 → 单项目指标 → 组合指标。

## 组合分析
分别计算单项目和项目群的投资、收入、EBITDA、现金流、项目IRR、资本金IRR、回收期和DSCR；同时识别共享平台、共享运维、共享融资和共享VPP产生的协同效应。

## 防重复
共享平台成本只能在一个边界内计入；VPP收益按资源归属分配；内部结算不能作为项目群外部新增收入。

## 输出
项目群总览表、单项目经济性、组合现金流、资金需求、建设时序、协同收益和风险集中度。
