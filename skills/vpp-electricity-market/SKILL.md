# 虚拟电厂与电力交易 Skill

## 资源范围
光伏、储能、充电桩、可中断负荷、空调、冷站、水泵、数据中心及其他可调资源。

## 资源画像
每项资源记录：额定功率、可调功率、响应时间、持续时间、可用时段、基线负荷、控制接口、计量方式和结算规则。

## 业务流程
资源接入 → 资源建模 → 负荷预测 → 组合优化 → 调度执行 → 计量核验 → 市场申报 → 结算 → 运营复盘。

## 电力交易口径
区分中长期交易、现货交易、绿电、绿证、需求响应、辅助服务和代理购售电。不得将不同市场的收益直接相加而不说明边界和结算条件。

## 收益测算
分别计算交易价差、需求响应补偿、辅助服务收入、聚合服务费、平台服务费和运营成本，并设置不确定性情景。

## 风险
市场规则、基线核定、资源可用率、偏差考核、调度执行、计量通信、价格波动和政策变化。
