# 电力交易与绿电绿证 Skill

## 目标
建立中长期、现货、绿电、绿证、需求响应及辅助服务的边界清晰、可结算收益模型。

## 建模原则
先确认项目所在省份/市场、市场主体身份、交易资格、结算周期、价格机制和偏差考核规则；政策和市场规则属于时效数据，使用前应核验最新官方文件。

## 收益结构
中长期合同价差、现货购售电价差、绿电环境属性价值、绿证收益、需求响应补偿、辅助服务收益、聚合运营服务费分别建模。

## 边界
绿电、绿证和碳资产不能在没有属性归属确认的情况下重复出售或重复计入减排收益。交易收益必须区分毛收益、交易费用、偏差考核和净收益。

## 数据要求
价格、交易量、结算电量、偏差电量、基准价、输配电价、政府性基金及附加、交易手续费等均保留来源、日期和单位。

## 输出
交易策略、价格序列、年度交易电量、毛收益、交易成本、偏差成本、净收益、敏感性及规则风险清单。
