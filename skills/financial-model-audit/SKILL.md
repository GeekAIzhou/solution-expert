# 财务模型深度审计 Skill

## 审计层级
输入假设 → 单位 → 技术规模 → CAPEX → 产能/负荷 → 收入 → OPEX → 折旧 → 税费 → 融资 → 年度现金流 → IRR/NPV/回收期/DSCR → 敏感性。

## 逐公式审计
每个关键单元格必须回答：公式是什么、引用了哪些输入、单位是什么、时间口径是什么、是否存在循环引用、是否存在重复计算、极端情况下是否合理。

## 四类校验
### 1. 维度校验
MW/kW、MWh/kWh、元/万元、含税/不含税、小时/年必须统一。

### 2. 逻辑校验
收入不能脱离产能；储能放电不能超过SOC可用能量；充电量不能超过设备能力；折旧年限不能超过模型寿命。

### 3. 会计校验
利润表、现金流、资产负债相关项目保持勾稽关系；融资不作为收入；折旧不作为现金流出。

### 4. 指标反算
用年度现金流重新计算IRR、NPV和回收期，并与模型结果逐项比对。

## 红线
关键指标空白、错误显示0、累计现金流断裂、项目IRR与现金流不匹配、资本金IRR混用项目现金流、重复计入储能收益、重复计入绿电/绿证/碳收益。

## 输出
错误清单、严重程度、影响金额、影响指标、修正公式、修正前后结果、待确认数据和审计结论。
