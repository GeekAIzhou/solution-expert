# 财务模型公式审计 Skill

## 审计顺序
输入假设 → 技术产能 → 投资 → 收入 → 成本 → 折旧 → 税费 → 融资 → 现金流 → 指标。

## 审计清单
- 单位：元/万元、kW/MW、kWh/MWh、含税/不含税
- 时间：建设期、运营期、贷款期、折旧期
- 投资：设备、安装、设计、管理、预备费、税费是否闭合
- 收入：发电、节能、充电、储能、VPP、交易是否重复
- 成本：运维、保险、租赁、交易费、替换、税费是否遗漏
- 税务：销项税、进项税、增值税、所得税、折旧抵扣
- 融资：资本金、贷款、利率、提款、还本、付息
- 现金流：建设期现金流、运营期现金流、期初期末余额
- 指标：项目税后IRR、资本金IRR、NPV、回收期、DSCR

## 回收期
累计净现金流首次大于等于零时，采用跨年插值；若全周期仍小于零，显示“项目期内未回收”，不得显示空白或0。

## 必须输出
1. 错误清单
2. 影响程度
3. 修正建议
4. 修正前后指标
5. 关键公式说明
6. 仍待确认的数据

## 红线
任何关键指标必须可追溯到输入、计算过程和现金流口径。
