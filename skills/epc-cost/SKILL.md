# EPC工程量与成本引擎 Skill

## 核心链路
项目边界 → WBS → 设备BOM → 工程量 → 询价/数据库 → 直接费 → 间接费 → 措施费 → 设计/管理 → 税费 → 预备费 → EPC总价。

## WBS标准
项目/子项目 → 系统 → 专业 → 设备/材料 → 安装 → 调试 → 服务。

## 能源项目重点
光伏：组件、逆变器、支架、汇流、箱变、并网、线缆、土建。
储能：电池舱/柜、PCS、变压器、EMS、消防、暖通、通信、土建。
充电：充电机/枪、配电、变压器、线缆、车棚、消防、平台。
路灯：灯具、杆件、控制器、通信、配电、平台。
污水厂：泵、风机、曝气、加药、控制、光伏、储能及改造接口。
数据中心：冷源、末端、泵组、冷却塔、液冷、配电及控制。

## 每项成本
编码、名称、规格、单位、数量、单价、不含税合价、税率、含税合价、价格来源、甲乙供边界、备注。

## 强制闭环
设备数量必须与技术规模匹配；容量必须与设备数量匹配；工程量必须与图纸/方案一致；分项合计必须等于总价；含税价可反算税额。

## 估价原则
没有可靠询价时必须标注“估算/暂估”，不得伪装成合同报价。不同地区、品牌、技术路线、交付边界应采用不同价格情景。

## 输出
设备清单、工程量清单、分项投资、EPC总价、单位投资、价格敏感性及甲乙供边界表。
